Jarvis プライバシーポリシー

Jarvis は作成者が自分ひとりで使う個人用のアプリです。

使うデータ

作成者自身のGoogleカレンダーの予定（タイトル・日時・通知）だけを使います。予定を読むことと、本人が承認した予定を追加することにだけ使い、削除や変更はしません。

保存と共有

データと認証情報は作成者のPCにだけ保存します。第三者への提供・販売・広告への利用はしません。

Googleのデータの扱い

Google APIから受け取った情報の利用は、限定使用の要件を含む Google API Services User Data Policy に従います。

連携の解除

Googleアカウントの「サードパーティのアプリとサービス」からいつでもアクセス権を削除できます。

Jarvis is a personal app used only by its author. It uses only the author's own Google Calendar events, to read them and to add events the author approves. Data and credentials stay on the author's own computer and are never shared, sold, or used for ads. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
